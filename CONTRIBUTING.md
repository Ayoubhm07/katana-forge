# Contributing to Katana Forge

The Forge grows one battle-tested move at a time. A contribution is welcome when it was **shipped on a real site**.

## Propose a signature move

Open an issue with the "Signature move" template and include:

1. **The meaning**: why this effect is right for its subject (an effect without a story is cut).
2. **The timeline** in milliseconds, the no-JS final frame and the reduced-motion state.
3. **The budget**: gzipped HTML, element count, First Load JS and Lighthouse before and after.
4. **A live link** and a short capture.
5. **The pitfalls** you paid for.

## Pull requests

- Keep `SKILL.md` lean: details go to `references/`. Describe a move in words: this repository never ships a site's source code.
- No em dashes, no emoji in the docs. Plain, measured English.
- Never add third-party code or images without a licence that allows redistribution, and list them in `NOTICE.md`.
