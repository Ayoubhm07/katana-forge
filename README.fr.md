<h3 align="center">Arrêtez de livrer des templates. Livrez le front end que les gens capturent en photo.</h3>

**Katana Forge** transforme Claude Code en une escouade de huit spécialistes nommés qui conçoivent, chorégraphient,
codent, inspectent et livrent des front ends que l'on appelle des chefs-d'œuvre, sans perdre un seul point de Lighthouse.

**À voir en vrai : [ayoubhammoudi.com](https://ayoubhammoudi.com)**, forgé avec ce plugin.

## Installation

```text
/plugin marketplace add Ayoubhm07/katana-forge
/plugin install katana-forge@katana-forge
```

ou `./install.sh` (macOS, Linux) et `./install.ps1` (Windows) après un `git clone`.

## Utilisation

```text
/forge Projet : mon portfolio. Code : ./site. Public : recruteurs Big Tech. Langues : fr, en.
```

ou simplement : « take this team front end and go wild ».
